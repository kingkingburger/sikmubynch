# SIKMUBYNCH 게임 디자인

## 디자인 목표

SIKMUBYNCH의 목표는 “전투 중에 방어선이 계속 흔들리고, 시너지 빌드업으로 그 압박을 이겨내는 호드 서바이벌 로그라이트”를 만드는 것이다. 핵심은 복잡한 운영량이 아니라, 화면에 보이는 물량 압박과 매 런 달라지는 빌드 선택이다.

플레이어가 화면에서 읽어야 하는 것은 두 가지다. **어디서 얼마나 많은 적이 몰려오는가**, 그리고 **내 방어선이 어디서 무너지고 있는가**. 모든 시스템과 비주얼은 이 두 가지가 즉시 보이도록 설계한다.

## 핵심 루프

```text
런 시작
→ 본진 주변에 최소 방어선 구축
→ 웨이브 압박 시작
→ 전투 중 건설, 레벨업, 유닛 생산, 임시 보강
→ 웨이브 클리어 또는 시간 경과
→ 보상 카드 선택
→ 특성/시너지 경로 확정
→ 더 큰 웨이브와 이벤트 압박
→ 본진 파괴 시 결과 확인
→ 새 런 시작
```

## 런 구조

| 항목 | 기준 |
| --- | --- |
| 런 길이 | 일반 목표 20~30분, 빠른 실패 3~8분 |
| 시작 상태 | 본진, 기본 바리케이드, 기본 타워, 제한된 미네랄 |
| 첫 압박 | 10초 안에 적 무리가 보이고 방어 판단이 필요해야 함 |
| 휴식 | 보상 선택 중에만 짧게 숨을 돌릴 수 있음 |
| 실패 | 본진 파괴. 결과 화면에서 도달 웨이브, 처치 수, 핵심 시너지 표시 |

## 웨이브 압박

### 현재 프로토타입의 런 상태 규칙

- 분열로 예약된 자식까지 모두 제거한 뒤 웨이브를 한 번만 종료한다.
- 보상 카드 선택 중에는 전투·생산·웨이브 시간이 멈춘다. 카드를 선택하거나 건너뛴 후 선택 이벤트가 있으면 이어서 한 개씩 표시한다.
- ESC 메뉴와 보상 선택은 각각 정지 사유를 유지한다. 메뉴를 닫아도 남아 있는 보상 선택이나 수동 일시정지는 해제하지 않는다.
- 수동 일시정지에서는 기존처럼 건설 판단을 할 수 있지만 전투와 스폰은 진행하지 않는다. 카드·선택 이벤트·ESC 메뉴·게임오버에서는 필드 건설과 철거 입력을 차단한다.
- 새 런은 자원·웨이브·길찾기·공간 검색·보상·정지 상태를 모두 초기화한다.

웨이브는 단순한 적 수 증가가 아니라 방향, 밀도, 정예, 이벤트 조합으로 압박을 만든다.

### 웨이브 타입

| 타입 | 목적 | 특징 |
| --- | --- | --- |
| 정찰 웨이브 | 새 런 적응 | 적 수는 낮지만 바로 압박이 보임 |
| 밀도 웨이브 | 방어선 테스트 | 약한 적이 넓은 전선으로 몰림 |
| 돌파 웨이브 | 취약점 공격 | 빠른 적이나 자폭 적이 특정 방향을 찌름 |
| 폭풍 웨이브 | 빌드 검증 | 대량 적, 정예, 이벤트가 함께 등장 |
| 보스급 압박 | 장기 생존 테스트 | 파괴자급 적이 방어선을 강제로 열게 만듦 |

### 압박 설계 원칙

- 적은 플레이어가 준비를 마친 뒤 오지 않는다. 준비와 전투가 겹쳐야 한다.
- 초반 압박은 죽일 만큼 강하지 않아도, “가만히 있으면 진다”는 사실을 보여야 한다.
- 중반 압박은 시너지 선택이 없으면 감당하기 어렵게 만든다.
- 후반 압박은 하나의 완벽한 벽이 아니라 여러 겹의 임시 방어선과 광역 화력으로 버티게 한다.
- 물량은 숫자가 아니라 화면이다. 중반에는 수백, 후반에는 수천 단위의 적이 실제로 화면에 보여야 한다. 성능을 이유로 스폰 수를 줄이지 않고 구조로 해결한다.
- 적이 남아 있는데 다음 압박이 겹치는 순간이 장르의 긴장감을 만든다.

## 플레이어 행동

| 행동 | 역할 |
| --- | --- |
| 바리케이드 배치 | 시간을 벌고 적 밀도를 원하는 위치로 유도 |
| 타워 배치 | 안정적인 원거리 화력 확보 |
| 배럭 배치 | 자동전투 유닛으로 전선을 넓힘 |
| 채굴기 배치 | 중장기 경제 확보 |
| 버프 타워 배치 | 특정 전선을 강화하고 시너지 카운트를 밀어줌 |
| 레벨업 | 이미 구축한 핵심 전선을 강화 |
| 철거 | 무너진 방어선을 정리하고 자원을 회수 |
| 보상 선택 | 다음 2~3웨이브의 대응 방향 결정 |

## 건물

| 건물 | 게임플레이 역할 | 유지 기준 |
| --- | --- | --- |
| HQ | 방어 대상, 최후의 보루 | 공격받는 순간 위험을 즉시 인지해야 함 |
| 바리케이드 | 싸고 약한 시간벌이 벽 | 많이 짓고 많이 부서지는 것이 정상 |

| 채굴기 | 경제 | 위험 지역 자원을 확보할 이유를 제공 |
| 버프 타워 | 전선 증폭 | 시너지 빌드와 배치 퍼즐을 연결 |

## 유닛

유닛은 직접 조작하지 않는다. 플레이어는 유닛을 배치하는 것이 아니라 생산 기반과 시너지 방향을 결정한다.

| 유닛 | 역할 |
| --- | --- |
| 솔저 | 기본 근접 전선 유지 |
| 아처 | 후방 원거리 보조 화력 |
| 탱커 | 누수 지점 시간벌이 |
| 폭탄병 | 밀집 적 처리와 위기 탈출 |

## 시너지 빌드업

시너지는 보상 카드의 부가 설명이 아니라 런의 방향을 정하는 핵심 시스템이다. 플레이어는 “지금 좋은 카드”와 “다음 단계 시너지를 여는 카드” 사이에서 선택해야 한다.

### 특성

| 특성 | 전투 정체성 |
| --- | --- |
| 화염 | 광역 피해, 지속 피해, 밀집 처리 |
| 냉기 | 감속, 동결, 전선 안정화 |
| 독 | 지속 피해, 방어 약화, 장기전 |
| 전기 | 연쇄 공격, 스턴, 다중 목표 처리 |
| 강화 | 체력, 방어, 건물 유지력 |

### 단계

| 단계 | 기대 체감 |
| --- | --- |
| Tier 1 | “이 빌드가 시작됐다”는 작은 성능 차이 |
| Tier 2 | 전투 방식이 보이게 달라지는 특수 효과 |
| Tier 3 | 위기 웨이브를 뒤집을 수 있는 강한 정체성 |

### 시너지 UI 원칙

- 현재 활성 단계와 다음 단계까지 필요한 카운트를 항상 보인다.
- 보상 카드에는 “선택 시 달성되는 시너지”를 명시한다.
- 시너지 발동은 사운드, 색상, 필드 효과 중 최소 2개로 피드백한다.

## 보상 카드

### 현재 프로토타입의 보상 적용 규칙

- 특성 카드는 이번 런의 전역 정수를 1개 늘린다. 개별 타워를 추첨하지 않는다. 특성이 없는 타워는 강화(Fortify)를 제외한 최다 정수의 속성을 공통으로 사용하며, 동률이면 먼저 획득한 속성을 유지한다. 건물·유닛별 특성 부여는 후속 구현 범위다.
- 유닛 공격력 카드·강화 이벤트는 이번 런 동안 누적되며 폭탄병의 폭발에도 적용된다.
- 건물 체력 카드는 이번 런의 모든 건물 최대 HP를 누적 증가시킨다. 현재 건물은 늘어난 최대 HP만큼 현재 HP도 증가하며, 이후 건설한 건물에도 적용한다. 전설 체력 카드는 증가 후 최대 HP의 표시 비율만큼 추가 회복한다.
- 강화 시너지 최대 HP, 건물 레벨 배율, 체력 카드 배율은 각각 곱한다. 교차 시너지의 공격력 보너스는 개별 속성 Tier 보너스에 더한다.
- 미네랄 2배 이벤트는 처치 보상에, 도전 보상 배율은 처치·클리어 보상에 적용한다. 두 배율은 곱하며 카드·채굴·선택 이벤트의 고정 지급에는 적용하지 않는다. 처치 보상은 사망 시 확정하므로 오브가 뒤늦게 도착해도 금액이 바뀌지 않는다.
- 독 전파 여부는 공격이 적중할 때의 효과에 포함한다. Tier 1 독은 전파하지 않고 Tier 2 이상 독은 처치 시 주변으로 전파한다.

보상은 웨이브 클리어 후 주어지는 다음 런 방향 선택이다.

| 보상 유형 | 예시 | 목적 |
| --- | --- | --- |
| 해금 | 배럭, 채굴기, 버프 타워 | 새 전략 축 제공 |
| 특성 부여 | 화염 타워, 냉기 바리케이드 | 시너지 카운트 증가 |
| 전역 버프 | 타워 사거리, 유닛 생산속도 | 현재 빌드 강화 |
| 위기 대응 | 즉시 수리, 무료 바리케이드 | 방금 무너진 구간 복구 |
| 고위험 보상 | 다음 웨이브 강화 대신 희귀 보상 | 욕심과 생존 사이 선택 |

## 이벤트

이벤트는 런마다 같은 빌드가 반복되는 것을 막는다. 단, 이벤트는 플레이어가 이해할 수 있어야 하며, 실패를 불합리하게 만들면 안 된다.

- 전투 이벤트: 적 속도 증가, 특정 방향 집중 스폰, 정예 예고, 보상 증가
- 선택 이벤트: 다음 웨이브 위험 증가 대 보상 강화, 건물 희생 대 시너지 강화
- 경고 기준: 치명적 이벤트는 최소 3초 전에 시각/청각 경고를 준다.

## 맵과 공간

맵은 단순 배경이 아니라 웨이브 압박을 읽고 방어선을 설계하는 판이다. 시점은 2D 쿼터뷰다. 평면 탑다운이 아니라 이소메트릭 시점이며, 3D 모델 디테일 대신 실루엣·색·밀도로 정보를 전달한다.

- 본진은 플레이어가 항상 위치를 이해할 수 있어야 한다.
- 적 타입은 실루엣과 색만으로 구분되어야 하고, 정예와 보스는 수천 마리 속에서도 즉시 보여야 한다.
- 밀도는 개체 겹침 자체로 표현한다. 겹침을 피하려고 간격을 벌리면 물량감이 사라진다.
- 자원 지대는 위험 지역에 배치해 확장 판단을 만든다.
- 스폰 방향은 미니맵과 경고 UI로 읽을 수 있어야 한다.
- 너무 넓어져서 압박이 분산되면 안 된다. 넓은 맵은 시야, 자원, 전선 선택으로 의미를 가진다.

## 게임 필

상용 기준에서 타격감은 장식이 아니라 정보다.

- 피격: 스프라이트 색 변화로 공격이 맞았음을 보여준다. 전체 화면 플래시는 쓰지 않는다.
- 처치: 적 크기와 가치에 맞는 파티클, 사운드, 화면 흔들림을 준다.
- 대량 처치: 짧은 히트스톱 또는 강한 사운드 레이어로 보상감을 준다.
- 방어선 붕괴: 건물 파괴, 경고음, 카메라 반응으로 위험을 즉시 알린다.
- 시너지 발동: 필드 효과가 실제 전투 변화와 연결되어야 한다.

## 비목표

- 정교한 RTS 자원 운영을 핵심으로 만들지 않는다.
- 유닛 직접 명령을 핵심 조작으로 넣지 않는다.
- 긴 캠페인 서사를 우선하지 않는다.
- 모든 시스템을 한 런에서 설명하려고 하지 않는다.
- 빌드 다양성보다 기능 수를 늘리는 방향으로 확장하지 않는다.
- 3D 모델 디테일이나 카메라 회전으로 볼거리를 만들지 않는다. 볼거리는 물량과 방어선 붕괴다.

# SIKMUBYNCH 제작 로드맵

## 로드맵 원칙

이 로드맵은 기능 목록을 많이 채우기 위한 문서가 아니다. 상용 호드 서바이벌 로그라이트로 보이기 위해 필요한 플레이 약속을 순서대로 검증하는 문서다.

우선순위는 다음과 같다.

1. 첫 화면에서 장르가 보인다.
2. 첫 30초 안에 압박이 느껴진다.
3. 시너지 선택이 전투 결과를 바꾼다.
4. 실패 후 다른 빌드를 시도하고 싶다.
5. UI, 사운드, 성능이 상용 빌드 기준에 접근한다.

## 단계 A: 문서와 포지셔닝 정리

**목표**: 프로젝트 설명, 게임 디자인, 기술 설계, 검증 기준을 새 장르 정의에 맞춘다.

결과물:

- `README.md` 장르 설명 갱신
- `docs/product-brief.md`
- `docs/game-design.md`
- `docs/technical-design.md`
- `docs/production-roadmap.md`
- `docs/quality-plan.md`
- 오래된 도구 중심 기획 문서 제거

완료 기준:

- 문서에서 특정 내부 도구나 임시 프로세스 이름이 사라진다.
- 외부에 보여줘도 되는 제품 설명이 존재한다.
- 구현 우선순위가 “기능 수”가 아니라 “플레이 약속”으로 정렬된다.

## 단계 B: 압박감 수직 절편

**목표**: 5분 안에 이 게임의 장르 약속을 보여주는 플레이 가능한 절편을 만든다.

범위:

- 런 시작 10초 안에 적 무리 시각화
- 첫 방어선이 실제로 밀리는 초반 리듬
- 스폰 방향 경고와 미니맵 또는 간이 위협 표시
- 웨이브 타입 구분: 정찰, 밀도, 돌파, 폭풍
- 기본 건물 3종의 선택 이유 명확화

완료 기준:

- 새 플레이어가 첫 런에서 “가만히 있으면 진다”고 이해한다.
- Wave 3 전후에 방어선 일부가 뚫릴 위험이 있다.
- 실패해도 원인이 본진 위험, 방어선 부족, 자원 선택 중 하나로 읽힌다.

## 단계 C: 시너지 빌드업 절편

**목표**: 보상 카드와 특성 시너지가 런 방향을 실제로 바꾸게 만든다.

범위:

- 보상 카드에 특성, 다음 시너지 단계, 즉시 효과 표시
- Tier 1/2/3 효과 재정의
- 최소 5종 특성의 전투 정체성 강화
- 시너지 발동 이펙트와 사운드 연결
- 결과 화면에 핵심 시너지 표시

완료 기준:

- 같은 웨이브라도 화염/냉기/전기 빌드 대응 방식이 다르다.
- Tier 2 이상 발동 시 플레이어가 화면 변화로 인지한다.
- 보상 선택에서 “지금 생존”과 “다음 단계 시너지” 사이의 고민이 생긴다.

## 단계 D: 중반 런과 맵 확장

**목표**: 15~20분 생존 구간에서 빌드와 방어선이 함께 성장하게 만든다.

범위:

- 자원 지대와 위험 지역 배치
- 채굴기 확장 동기 강화
- 2~4방향 스폰 압박
- 정예 적과 이벤트 조합
- 카메라, 미니맵, 위협 레이더 정리

완료 기준:

- Wave 10 전후에 200+ 적 규모가 보인다.
- 플레이어가 본진 주변만 막는 전략에서 확장 전략으로 넘어갈 이유가 있다.
- 정예 등장 시 즉각적인 경고와 대응 판단이 가능하다.

## 단계 E: 게임 필과 상용 표현

**목표**: 프로토타입처럼 보이는 구간을 줄이고, 반복 플레이를 견디는 피드백을 만든다.

범위:

- 피격/처치/파괴/시너지 발동 피드백 정리
- BGM 전환과 핵심 SFX 1차 품질 확보
- UI 색상, 여백, 정보 우선순위 정리
- 모델 스케일과 실루엣 통일
- 화면 흔들림과 히트스톱 강도 조정

완료 기준:

- 대량 처치가 시각과 청각 모두에서 쾌감으로 느껴진다.
- 방어선 붕괴와 본진 위험을 UI 없이도 어느 정도 인지할 수 있다.
- 스크린샷 한 장으로 장르가 전달된다.

## 단계 F: 상용 빌드 준비

**목표**: Steam Early Access 또는 데모 공개를 검토할 수 있는 안정성을 확보한다.

범위:

- 20~30분 런 안정성
- 설정 저장, 언어 전환, 볼륨 제어
- 크래시/프리즈 재현 루트 정리
- 업적/통계 후보 정의
- 스토어 페이지용 스크린샷/짧은 설명/긴 설명 준비
- 라이선스와 외부 에셋 출처 확인

완료 기준:

- 최소 10회 연속 런에서 치명적 크래시가 없다.
- 500+ 적 상황에서 목표 성능에 근접한다.
- 스토어 설명과 실제 게임 화면이 같은 약속을 한다.
- 출시 전 남은 리스크가 문서화되어 있다.

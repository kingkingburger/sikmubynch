# SIKMUBYNCH (식무변처)

데아빌식 대규모 웨이브 압박과 시너지 빌드업을 얹은 2D 쿼터뷰 호드 서바이벌 로그라이트.

SIKMUBYNCH는 플레이어가 한 런 동안 본진을 지키며 전투 중 건설, 유닛 생산, 보상 선택, 특성 시너지를 계속 쌓아 올리는 생존 게임이다. 적은 쉬지 않고 몰려오며, 플레이어는 방어선을 임시로 막고, 화력을 집중하고, 다음 보상 선택으로 빌드 방향을 굳히며 더 큰 웨이브를 버틴다.

## 핵심 경험

- **대규모 웨이브 압박**: 초반부터 적 무리가 보이고, 중후반에는 수천 단위의 호드가 방어선을 밀어붙인다.
- **전투 중 건설 판단**: 안전한 준비 페이즈가 아니라, 무너지는 방어선을 보며 즉석에서 바리케이드와 타워를 보강한다.
- **시너지 빌드업**: 건물, 유닛, 보상 카드가 특성 태그를 만들고, 누적된 조합이 전투 방식 자체를 바꾼다.
- **런 기반 로그라이트**: 매 런마다 맵, 보상, 이벤트, 시너지 경로가 달라지고, 실패 후 바로 다른 빌드를 시도하게 만든다.
- **상용 게임 기준의 피드백**: 타격감, UI 가독성, 사운드, 성능, 밸런스를 별도 검증 대상으로 둔다.

## 현재 상태

현재 구현은 상용 출시용 완성본이 아니라 핵심 전투 감각을 검증하는 프로토타입이다. M1~M7 범위의 여러 시스템이 들어갔지만, 기준은 기능 보유 여부가 아니라 “대규모 압박이 보이는가”, “시너지 선택이 전투 결과를 바꾸는가”, “한 판 더 하고 싶은가”로 재정렬한다.

구현 이력:

- M1: 3D 이소메트릭 맵, 본진, 바리케이드, 적 스폰, 게임오버
- M2: 타워, 발사체, 레벨업, 철거, 멀티웨이브
- M3: 배럭, 4종 아군 유닛, 자동전투 AI
- M4: 6종 적, Flow Field 길찾기, 파도형 난이도, 미네랄 오브
- M5: 5종 특성 시너지, 보상 카드 3택, 이벤트, 채굴기, 버프 타워
- M6: 화면 흔들림, 히트스톱, 카메라, 속도 조절, 드래그 배치
- M7 이후: 256 맵 확장, StarCraft식 UI, 로우폴리 GLB 모델, 파티클, 로컬라이제이션

2026-09-16에 3D를 버리고 2D 쿼터뷰로 전환하며, 적·유닛·발사체를 Node에서 떼어내 시뮬레이션 배열로 옮기기로 결정했다. 엔진은 Godot을 유지한다. 현재 코드는 아직 3D 프로토타입이며, 전환 순서는 [기술 설계](docs/technical-design.md)를 따른다.

## 실행

Godot 에디터에서 `project/` 폴더를 열고 F5로 실행한다.

회귀 검증은 PowerShell에서 Godot 실행 파일 경로를 지정해 실행한다.

```powershell
./tools/run-gameplay-tests.ps1 -GodotPath 'D:/Godot_v4.6.1-stable_win64.exe/Godot_v4.6.1-stable_win64_console.exe'
```

분열 적, 길찾기, 재시작, 일시정지, 보상 선택, 시너지·영구 보너스를 검증하며 실패 시 nonzero로 종료한다. 상세 실행·플레이 결과는 [런 안정화 검증 기록](docs/verification/2026-09-08-run-stability.md)에 남긴다.

## 프로젝트 구조

2D 전환 후 목표 구조다. 현재 저장소에는 3D 프로토타입의 `scenes/enemies`, `scenes/units`, `scenes/projectiles`, `assets/models`가 남아 있으며 전환 단계에서 제거한다.

```text
project/
├── autoloads/          # 게임 상태, 시너지, 이벤트, 사운드 등 싱글톤
├── sim/                # Node 없는 시뮬레이션: 적, 전투, 웨이브, Flow Field, Spatial Grid
├── render/             # 시뮬레이션 상태를 2D로 배칭 그리는 렌더러
├── scenes/
│   ├── main/           # 타이틀, 메인 게임 씬
│   ├── buildings/      # HQ, 바리케이드, 타워, 배럭 등 (Node 허용)
│   └── ui/             # HUD, 보상 카드, 메뉴, 레이더
├── scripts/            # 게임플레이 helper와 데이터 클래스
│   └── data/           # Resource 데이터 정의
└── assets/             # 스프라이트 아틀라스, 사운드

docs/                   # 상용 개발 기준 문서와 제작 가이드
tools/                  # 에셋 생성 및 보조 도구
```
